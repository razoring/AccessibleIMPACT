3. INTERACTIVE ELEMENTS & NAVIGATION CAPABILITY
--------------------------------------------------------------------------------
Interactive controls within the instructions panel are fully navigable via
Playwright snapshot + dispatch. List of actionable items observed on page:

A. STEP NAVIGATION (from .steps):
   - BUTTON[class="direction-left"]   -> move BACK to previous step (disabled state on step 1)
   - BUTTON[class="direction-right"]  -> move FORWARD to next step (active on current step)
   Both are real <button>s; aria-label not explicitly set but accessible via class.

B. INSTRUCTION BUTTONS (within instructions panel):
   - BUTTON "Hint"              -> opens/reveals hint content (subtitle line shown above paragaph 3)
   - BUTTON "SUBMIT"             -> submits the level solution
        class: "nav-btn-green btn-disabled" -> enabled after solution meets criteria; disabled here

C. CHALLENGE CONTROLS (top of panel):
   - BUTTON "PROVE MYSELF!"     -> challenge header (action prompt)
   - BUTTON "Activity Action" (x2)
   - BUTTON "SENSEI HELP"       -> teacher hint shortcut

6. SUMMARY
--------------------------------------------------------------------------------
The instructions panel structure supports keyboard and assistive-technology
navigation through standard Angular form controls (.steps, .direction-left/.right,
.step span) plus native <button> elements for Hint and SUBMIT. Playwright can
interact with all of these (hover/snapshot-based targeting). The only true
gating is SUBMIT being disabled until the player's block-assembly matches the
expected solution.
